# Issue #03: 📸 Panel Screenshot Export (html2canvas)

**Labels**: `enhancement`, `good first issue`, `frontend`  
**Difficulty**: `Easy`  
**Target Files**: [`public/index.html`](../public/index.html), [`public/app.js`](../public/app.js), [`public/styles.css`](../public/styles.css)

---

## 📌 Problem & Context

Researchers and academics using AbstractiFy often want to share generated insights — such as the Consensus Meter, Study Comparison Matrix, or Interactive Citation Network — in presentations, tweets, or research papers. Manually taking manual OS screenshots requires cropping and lacks branding.

---

## 🎯 Goal

Add a **"Share as Image" (📸)** button to panel header toolbars (Consensus Meter, Matrix, Citation Network Graph) that converts the DOM element into a crisp PNG image using [html2canvas](https://html2canvas.hertzen.com/), attaches an AbstractiFy watermark, and triggers an automatic browser download.

---

## ⚙️ Technical Specification

### External Dependencies (CDN)
Add to `public/index.html`:
```html
<script src="https://cdn.jsdelivr.net/npm/html2canvas@1.4.1/dist/html2canvas.min.js"></script>
```

### UI & Logic Implementation
1. **Header Button**: Add a camera icon button (`<button class="btn-export-screenshot" title="Export Panel as PNG">📸</button>`) to panel headers.
2. **Export Handler in `public/app.js`**:
   ```javascript
   async function exportPanelAsImage(panelId, filename) {
     const panelEl = document.getElementById(panelId);
     const canvas = await html2canvas(panelEl, {
       backgroundColor: '#0F172A', // Dark slate background matching app theme
       scale: 2,                   // High resolution (Retina display quality)
     });
     
     // Append subtle AbstractiFy watermark to bottom-right before saving
     const ctx = canvas.getContext('2d');
     ctx.font = 'bold 16px Inter, sans-serif';
     ctx.fillStyle = 'rgba(255, 255, 255, 0.4)';
     ctx.fillText('Generated by AbstractiFy • abstractify1.netlify.app', canvas.width - 420, canvas.height - 20);

     const link = document.createElement('a');
     link.download = `${filename}_${Date.now()}.png`;
     link.href = canvas.toDataURL('image/png');
     link.click();
   }
   ```
